Ignored URL Parameters

Some parts of a web address don't change the page, like a video's start time or a tag saying which site sent you. Pages that differ only in these parts count as the same page. The defaults already cover common tracking tags and popular sites, so most people never need to change this.

One rule per line: a comma-separated list of parameter names, optionally preceded by one or more domains and a colon to apply it to those sites only. A trailing * matches any parameter with that prefix. Lines starting with # are comments.

Saving merges marked pages that become identical under the new rules. This can't be undone by removing a rule later, so export a backup first.
